# Current margin reference

Read [ICON_RULES.md](ICON_RULES.md) before revising icon size or margins. Current production artwork is the 94-pair native source collection. Preserve each source's optical placement, effective paint bounds and natural proportions; do not apply superseded legacy frame dimensions to it.

Measure actual visible edges, including stroke caps, joins, authored expanded shapes and transparent counters. Inspect native sizes and light/dark surfaces in the packed Lab. A newly requested size/margin change needs an explicit owner decision and source update; packaging must not rescale artwork.
